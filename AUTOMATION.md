# Automated rental refresh

The repository now has a scheduled live-verification and discovery pipeline in `.github/workflows/refresh-listings.yml`.

## Schedule

The workflow runs every 6 hours and can also be started manually with **Actions → Refresh rental inventory → Run workflow**.

## What it does

1. Launches Chromium through Playwright.
2. Re-opens every `active` and `needs_confirmation` listing from `data/listings.json`.
3. Saves a fresh evidence snapshot under `data/evidence/`.
4. Auto-removes a listing only when the matching live page contains an explicit inactive/unavailable signal.
5. If a previously Active URL cannot be live-verified on two consecutive runs, it is hidden as `needs_confirmation` instead of being assumed Active.
6. Collects high-recall discovery candidates from the source registry in `data/live-sources.json`.
7. Keeps discovered-but-not-yet-publishable rentals in `data/candidates.json` rather than polluting the public Active list.
8. Tracks live verifier health and source coverage in `data/refresh-state.json`.
9. Records safe direct-detail price changes in `data/history.json`.
10. Commits changed data back to `main`, which in turn refreshes GitHub Pages and the existing image-cache workflow when applicable.

## Safety / precision rules

- Search/index pages discover candidates; they do not prove availability.
- Explicit live inactive/unavailable evidence can remove a matching listing automatically.
- A blocked page is never interpreted as a removed listing.
- Repeated verification failures hide a listing instead of deleting its history.
- New candidates are not automatically published until enough structured evidence exists to establish identity, availability, location and core rental fields.
- Price auto-updates are deliberately limited to direct detail pages on approved hosts such as Zumper and RentFaster.

## Source coverage

`data/live-sources.json` is the registry for automated discovery. It currently includes Zumper Kitsilano and West Point Grey, RentFaster Vancouver, Kits Walk, Arbutus Terrace, Arbutus Residences, Homax/Arbutus Rental, and 19 on the Greenway.

Add new public discovery lanes to this registry rather than hard-coding them into the crawler.

## 2477 Waterloo

`2477 Waterloo St` is included as a seed candidate with the user's current observed rent of `$4,950`. Each refresh attempts to load the direct Zumper address page and records the live price/status separately from stale search-index prices.

## Files generated by automation

- `data/candidates.json` — discovered candidate pool, not automatically public
- `data/refresh-state.json` — verifier/source health and latest extracted fields
- `data/evidence/<listing-id>.json` — latest direct-page evidence for tracked rentals
- `data/evidence/source-*.json` — latest discovery-page evidence
- `data/evidence/candidate-*.json` — latest direct evidence for seed candidates

The intent is high recall during discovery and high precision for the public Active inventory.
